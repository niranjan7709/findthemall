# FIND THEM ALL

A 2D indie game built in **Godot**, where players navigate through distinct levels, fight enemies, and collect unique sprites to unlock the path to the next level.

## Online Demo

You can play the latest work-in-progress build directly in your browser:
• Web Demo: [Play the Live Build](https://niranjan7709.itch.io/find-them-all)

> [!NOTE] 
> AI was used for debugging and assisting with code structure and README enhancements.

---

## Features

• Sprite Collection: Explore levels to find and collect all unique hidden sprites scattered across the map.
• Diverse Terrains: Navigate through unique environments featuring distinct platforming challenges.
• Enemy Combat: Fight and evade enemies that stand between you and your collection goals.
• Progression System: Successfully clearing a level unlocks the path to the next stage.

> *Note: This game is currently a Work in Progress (WIP). Multi-level progression and additional sprites are actively under development.*
